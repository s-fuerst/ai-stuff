# Kaufreport: Stopfeier / Stopfpilze

**Datum:** 2025-08-18
**Anfrage:** Stopfeier (zum Löcher-in-Socken-Stopfen) als Set in verschiedenen Farben, aus einem deutschen Shop (kein Amazon).

---

## Zusammenfassung

Ein **fertiges Set aus mehreren farbigen Stopfeiern** ist in deutschen Shops (außerhalb Amazon) kaum erhältlich. Die meisten Stopfeier/Stopfpilze sind:

- naturbelassenes Buchenholz, oder
- klassischer roter Fliegenpilz (z. B. Prym).

Farbig lackierte Exemplare existieren, werden aber überwiegend als **Einzelstücke** mit „farbig sortiert" (= zufällige Farbe, kein Farbwunsch) angeboten. Praktisch empfiehlt sich daher, sich das bunte Set **selbst aus mehreren Einzelstücken** zusammenzustellen.
